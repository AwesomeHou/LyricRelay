# 安全与隐私边界

LyricRelay 的 MVP 是局域网设备工具，不建立用户账号，也不把播放数据上传云端。安全设计围绕“只让已配对设备互通”和“只收集完成同步所需的数据”。

## 数据最小化

传输字段限于：歌曲标题、歌手、专辑、时长、播放器包名、播放状态、位置和速度，以及设备连接所需的标识。MVP 不传输：

- 手机音频或麦克风内容。
- 账号、联系人、播放历史或歌单。
- 歌词正文（歌词由 Windows 侧 Provider 获取）。
- 与同步无关的系统信息。

## 权限

- Android 只申请读取活跃 MediaSession 所需的系统授权。
- Android 使用相机权限扫描 Windows 的一次性 QR；不保存或上传扫描画面。
- 不申请 AudioPlaybackCapture、麦克风、联系人或账号权限。
- Windows 只申请本地网络通信、开机启动（用户开启时）和任务栏渲染所需能力。

## 配对与连接

- QR 内容使用短期、一次性的配对信息，不能作为长期设备凭据。
- 配对完成后双方保存随机设备标识和设备密钥；后续连接必须校验已绑定设备。
- 服务发现只负责找到候选设备，不能单独授予连接权限。
- 连接层必须限制在用户选择的局域网监听范围，不能默认暴露到公网。
- 连接消息校验协议版本、字段范围和消息新旧顺序。
- 当前实现使用 TLS 1.2/1.3 长连接；Windows 自签名证书指纹放入 QR，Android 只信任该指纹。
- 首次配对使用短期 token；token 被消费后不能重复使用。
- 后续连接校验 Android 设备 ID 和配对设备密钥；未知设备被拒绝。
- 服务发现只更新候选地址和证书指纹，不绕过 TLS、设备 ID 或设备密钥校验。
- 当前连接监听为局域网 TCP/UDP 端口，不实现公网穿透或端口转发。

## 本地存储

- Windows 优先使用当前用户证书存储保存 TLS 身份；受限环境的回退文件使用当前用户 DPAPI 保护，必要时只在内存中使用证书。设备密钥和必要设置也使用本地受保护存储。
- Android 使用 Android Keystore 保护设备密钥。
- 日志中禁止输出配对 token、设备密钥、完整 QR 内容和歌词全文。
- 用户关闭自动连接或解除配对时，删除对应设备凭据。

## 威胁与降级

MVP 主要防护误连接、局域网内的普通未授权客户端和日志泄露；不承诺防御已完全控制用户设备或局域网的攻击者。任何认证失败、协议异常或未知设备连接都应被拒绝，并保持客户端可用。
