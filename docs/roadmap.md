# 产品路线图

## V0.1 / MVP：同步歌词

只完成以下闭环：

1. QR 配对和同一局域网自动连接。
2. Android MediaSession 读取与标准化。
3. 至少一个合规的同步歌词 Provider。
4. LRC 解析和本地时间轴同步。
5. Windows 任务栏单行/双行渲染。
6. 开机启动、自动连接、歌词开关和基础样式设置。

退出条件是自动、快、准、稳、无感五项体验成立，而不是堆积设置或播放器适配数量。

## V0.2：实时字幕探索

候选方向是 Android 音频捕获、Windows ASR 和任务栏实时字幕。它会引入权限、隐私、延迟和算力问题，必须作为独立方案评估，不能提前污染 V0.1 的协议和模块边界。

## 后续候选

- 多歌词源和本地缓存。
- 双语歌词和更丰富的样式。
- 播客 transcript、实时翻译和 AI 摘要。
- macOS、iOS 和多设备连接。

这些内容在 MVP 阶段都不进入实现任务，也不应以“顺便支持”的方式加入当前模块。
